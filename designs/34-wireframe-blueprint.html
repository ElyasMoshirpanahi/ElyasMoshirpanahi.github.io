Interface · B2B partner API

Anonymized risk data, built for insurers

Insurance companies plug into FitInsured to underwrite on real behavior. Query aggregated, privacy-preserving risk signals through a documented REST API — no PII leaves the enclave.

GET /v1/risk/cohort 
# Anonymized cohort risk score
curl https://api.fitinsured.com/v1/risk/cohort \
  -H "Authorization: Bearer $KEY" \
  -d cohort="age:30-39;region:EU"

# → response
{
  "risk_index": 0.62,
  "activity_pct": 78,
  "sample_size": 14204,
  "pii": null
}
  • Aggregated risk indicesCohort-level scores derived from live wearable data — never individual records.
  • Privacy by designDifferential-privacy thresholds and k-anonymity enforced before any response leaves our systems.
  • Drop-in REST + webhooksVersioned endpoints, OpenAPI spec, and sandbox keys so your team ships underwriting logic in days.
  • Compliance-readySOC 2 controls, regional data residency, and full audit logs on every query.
